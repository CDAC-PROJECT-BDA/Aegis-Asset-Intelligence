# Aegis Asset Intelligence 🛡️

A portfolio project demonstrating a modern, AI-driven predictive maintenance pipeline. 

## Features
- **Machine Learning**: XGBoost model predicting pump failures from live sensor data.
- **RAG & LangGraph**: Agentic chatbot that automatically pulls equipment manuals (ChromaDB) when a failure is detected.
- **Model Context Protocol (MCP)**: The agent accesses data strictly via standardized MCP tools.
- **Guardrails AI**: Validates LLM inputs to block prompt injection attempts.
- **Live IoT Ingestion**: A decoupled SQLite architecture mimicking real edge-device telemetry.
